# Калькулятор накоплений на мечту 🚀

Простой скрипт на Python 3.12, который помогает рассчитать время, необходимое для покупки игрового ноутбука или любой другой цели.

## 💻 Функционал:
- Расчет ежемесячной суммы отчислений на основе процента от дохода.
- Проверка ошибок ввода (защита от случайных букв вместо цифр).
- Точный расчет количества месяцев до достижения цели.

## 🛠️ Как запустить:
1. Установите Python 3.12+
2. Запустите файл main.py через терминал.
